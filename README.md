# Game Leaderboard Management System

## Project Overview
A Java-based leaderboard management system designed
to manage player scores and rankings in online games.

## Features
- Add new players
- Update player scores
- Display complete leaderboard
- Display Top 10 players
- Automatically update player rankings

## Data Structures Used
- AVL Tree: Maintains players in sorted score order.
- Max Heap: Retrieves the highest-scoring players.

## Technologies
- Java
- Java Swing
- IntelliJ IDEA
- Maven

## How to Run
1. Open the project in IntelliJ IDEA.
2. Run the Main.java file.
3. Use the GUI to add players and manage scores.
